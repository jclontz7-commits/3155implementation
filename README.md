# 3155implementation

A lightweight student portal login demo built with plain HTML, CSS, and JavaScript.

## Run locally

From the project directory, start a static server:

```sh
python3 -m http.server 8000
```

Open <http://localhost:8000> in a browser.

## Demo student credentials

- Username: `student`
- Password: `student123`

This is a front-end prototype only. Credentials and session state are handled in the browser; do not use it for real accounts or production authentication. Professor sign-in and account registration are separate navigation destinations and are not implemented in this student login demo.
