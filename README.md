# 3155implementation

A lightweight student research listings prototype built with plain HTML, CSS, and JavaScript.

## Run locally

From the project directory, start a static server:

```sh
python3 -m http.server 8000
```

Open <http://localhost:8000> in a browser.

## Listings

The page uses sample research opportunities. Search matches titles, descriptions, faculty, departments, and research areas. Use the sort menu to order by newest, title, or application deadline.
